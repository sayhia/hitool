# HiTool 前端框架:回归行业标准布局 — 设计文档

- 日期:2026-09-08
- 状态:已获用户认可(经 12 种骨架方案对比 + 高保真示意确认)
- 前置:2026-09-08 曾实施"顶栏 + 滑出抽屉"方案,用户反馈四个痛点后决定推翻该方向

## 背景与问题

"顶栏 + 抽屉"方案上线后,用户反馈:

1. **启动直达工具后没有落脚点** — 没有全局入口的"家"
2. **满宽内容太空旷** — 工具内容铺满整个窗口宽度,视觉节奏差
3. **顶栏太挤/元素杂** — 品牌标志、侧栏开关、标签页全挤在 40px 横条里
4. **抽屉遮挡内容** — 滑出抽屉盖住工具内容,视觉跳动大

经方案对比(常驻侧栏、图标栏、停靠抽屉、菜单栏、启动器、Dock、双列、分类条、浮动胶囊、多窗口、纯命令面板),用户选定:**采用行业惯用范式**(DevToys / Postman / VS Code 一类):常驻左侧导航 + 顶部纯标签页,并恢复启动首页。

## 目标 / 非目标

**目标**

- 回归经典三区骨架:常驻侧栏 + 纯标签顶栏 + 内容区
- 启动落在首页,首页作为固定标签永远可达
- 工具内容居中限宽,解决空旷感
- 保留本轮已验证有价值的能力(标签溢出下拉、右键菜单、检查器、⌘K)

**非目标(明确不做)**

- 不动 ToolFrame 插槽契约,50+ 工具组件零改动
- 不动设置弹窗、任务坞、命令面板的内部实现
- 不新增功能;不引入抽屉、悬浮层等非常规形态

## 设计

### 1. 骨架(AppShell / TabStrip / SideTree)

```
┌─────────┬──────────────────────────────┐
│         │ 标签页  标签页  标签页    [检查器]│ ← 40px 顶栏(纯标签)
│  侧栏    ├──────────────────────────────┤
│  232px  │                              │
│  常驻    │        工具内容(居中限宽)      │
└─────────┴──────────────────────────────┘
```

- **SideTree 恢复为 flex 常驻子元素**(宽 `--side-w: 232px`):品牌 + 过滤框 + 收藏组 + 分类树(带计数)+ 底部主题/设置/更新。以 git 历史中的重构前版本为基础恢复,仅做小幅打磨;删除全部抽屉化代码(fixed 定位、遮罩、Transition、自动关闭 watcher)。
- **TabStrip 回归纯标签栏**:移除品牌标志与侧栏开关(品牌回侧栏);保留标签拖拽排序、中键关闭、右键菜单、溢出下拉、检查器按钮。
- **侧栏可折叠**:`sidebarOpen=false` 时侧栏整体隐藏(宽 0),此时顶栏左端出现唯一的展开按钮(仅折叠态可见)。展开/折叠状态持久化。

### 2. 启动与首页(HomeView)

- **"/" 路由 = 首页**;删除 RedirectView,不再自动跳转上次工具。
- 首页是**固定在标签栏第一位、不可关闭、不可拖动的标签**(类似浏览器新标签页 / VS Code 欢迎页)。启动总是落在首页;历史标签恢复后在旁边,点击即回。
- 首页内容克制:搜索框(点击打开 ⌘K 面板)+ 最近使用 + 收藏,仅此三块。
- 标签栏为空(无工具标签)时依然显示,只含首页标签。

### 3. 细节规则

- **内容居中限宽**:ToolFrame 外层新增居中容器 `max-width: var(--content-w)`(1120px);ToolFrame 新增可选 prop(如 `wide`)供个别宽工具(图片对比等)放宽,默认限宽。
- **快捷键**:
  - ⌘B = 折叠/展开侧栏(固定别名,不可被重绑定覆盖)
  - ⌘K / ⌘T = 命令面板;⌘J = 任务坞;⌘1-9 = 切换标签(不变)
  - 数字键 1-9(无修饰键)= 侧栏展开并滚动到对应分类(恢复重构前行为,不再有跳转)
- **状态持久化**:`layout.sidebar` = "1"/"0"(默认展开);标签恢复逻辑不变;首页标签不参与持久化(始终存在)。
- **清理**:`--drawer-w` 令牌移除、`--side-w` 恢复;新增 `--content-w: 1120px`;删除 RedirectView.vue。
